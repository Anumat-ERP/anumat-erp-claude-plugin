# JTBD switch interview guide

For someone who recently switched how they handle the problem (new tool, new
hire, new spreadsheet, or dropped a product). Method:

## Open (2 min)

"We want to understand the story of how you came to use [new thing]: the
whole thing, from when you first thought about changing. Small details help."

## Timeline

| Step | Questions | Notes (dates, people, places) |
|---|---|---|
| First thought | When did you first think the old way wasn't working? What was happening? | |
| Passive looking | Did you notice options before you actively searched? Where? | |
| Event / active looking | What happened that made you start searching seriously? Who else was involved? | |
| Deciding | What did you compare? What was the trade-off? What almost made you not switch? | |
| Buying / starting | What happened the day you bought or started? Who signed or paid? | |
| Using | What were the first days like? What surprised you? Is it doing what you hoped? | |

## Four forces

| Force | Probe | What they said (verbatim where possible) |
|---|---|---|
| Push (problem with old way) | What was the last straw? | |
| Pull (attraction of new) | What did you picture being different afterwards? | |
| Anxiety (about new) | What worried you about switching? | |
| Habit (comfort of old) | What was hard to give up? What do you miss? | |

## Job statement draft

When ____, I want to ____, so I can ____.

## Close

Ask for one commitment or two intros. Record what they agreed to.
