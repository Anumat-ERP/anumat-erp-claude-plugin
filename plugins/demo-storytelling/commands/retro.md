## Steps

**1. Facts first.** Gather planned versus actual: length, whether the ask was
reached, the outcome, failures and the recovery rung used. Read the plan,
script and rehearsal notes if they are in the project. Ask the user for
what isn't written down, one question at a time.

**2. Feedback.** What judges or the audience said, and the questions asked
that the team hadn't prepared. Add those to the Q&A prep sheet for next time.

**3. Keep, change, try.** At least one of each. Keep it about the process,
not people.

**4. By stage.** Walk the pipeline (story, script, demo setup, rehearsal,
warm-up and tech check, delivery, Q&A) and note one fix per stage where
something went wrong. Point each fix at the reference file that covers it.

**5. Actions.** Every fix becomes an action with an owner and a date. Three
actions done beats ten listed.

**6. Follow-ups.** People met and promises made at the event, with owners.
These go cold within days.

## Output

The filled retro. Suggest saving it next to the demo script in the project so
the next demo starts from it.
