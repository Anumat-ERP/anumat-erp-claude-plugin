# Tech-check checklist

Run by the driver 60 to 30 minutes before the slot. Background in
`${CLAUDE_PLUGIN_ROOT}/skills/demo-storytelling/reference/warmup.md` and `${CLAUDE_PLUGIN_ROOT}/skills/demo-storytelling/reference/demo-design.md`.

## Power
- [ ] Laptop at 100%, charger at the stage
- [ ] Phone charged; power bank
- [ ] Clicker batteries fresh; clicker paired and tested

## Connection and display
- [ ] Stage cable connected with our adapter; spare adapter in pocket
- [ ] Mirroring on (or extended, if using presenter notes)
- [ ] Resolution matches the projector; nothing cut off at the edges
- [ ] Readable from the back row (checked in person)

## Network
- [ ] Venue Wi-Fi joined and a page loads
- [ ] Phone hotspot on standby; password known
- [ ] Steps that need the network: ____________

## Quiet
- [ ] OS Do Not Disturb / focus mode on
- [ ] Chat, mail, calendar, updates, sync apps quit
- [ ] Phone on silent, face down

## Browser and app
- [ ] Browser zoom at ___% (125 to 150)
- [ ] Tabs open in script order; all others closed
- [ ] Bookmarks bar and extension icons hidden
- [ ] Logged in to every account in the script; sessions won't expire in the next hour
- [ ] Autocomplete from personal history off, or a clean profile
- [ ] Cursor size increased

## Data
- [ ] Reset run; first screen matches row 1 of the script
- [ ] Pre-filled forms in place

## Backup
- [ ] Backup video on the desktop, opened once, plays
- [ ] Same video on a USB stick
- [ ] Same video in the cloud, link ready
- [ ] Spare laptop / phone ready, logged in (if available)

## Final
- [ ] One silent click-through of the golden path
- [ ] Reset again
- [ ] Hands off the laptop until the slot
