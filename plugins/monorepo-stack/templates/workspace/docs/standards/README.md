# Standards

- **Code quality** — naming, constants, function shape: see the
  `monorepo-stack` skill's code-quality reference.
- **Testing** — what belongs at each layer, and why the domain layer is tested
  without a DOM.
- **Commits and branches** — conventions, and what a PR must include.

Standards are enforced by tooling wherever that is possible, and written down
only where it is not. A standard that only exists in a document is a standard
that is followed until the first deadline.
