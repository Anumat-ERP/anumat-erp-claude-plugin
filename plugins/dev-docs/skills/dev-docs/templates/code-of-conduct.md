# Code of conduct

This project follows the
[Contributor Covenant, version <3.0>](https://www.contributor-covenant.org/version/<3/0>/code_of_conduct/).
Check the site for the current version and use its exact URL.

Everyone taking part in this project, in issues, pull requests,
discussions, chat, and events, is expected to follow it.

## Scope

It applies in all project spaces, and when someone represents the project
in public spaces.

## Reporting

If you experience or see behaviour that breaks the code of conduct, report
it to:

- <Name or team>: <email address monitored by at least two people>

Reports are handled in confidence. You will get an acknowledgement within
<3 working days>.

If the report concerns one of the people above, contact <alternative
contact> instead.

## Enforcement

The people named above review and act on reports, following the
enforcement guidelines in the Contributor Covenant. Actions range from a
private warning to a permanent ban.
